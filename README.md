# Perudo 🎲

Le jeu de dés menteur, jouable dans le navigateur : en solo contre l'ordi ou en ligne avec des amis (pair à pair, sans serveur).

- Règles activables : Dudo, Calza, Pacos jokers, Palifico, nombre de dés
- Installable sur téléphone (PWA), mode solo hors connexion
- Multijoueur via PeerJS (WebRTC) : chaque joueur ne reçoit que ses propres dés

Site : https://maeldubreu-jpg.github.io/perudo/
